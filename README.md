# NDGroup Xếp TKB THPT V1

Trang web xếp thời khoá biểu tự động cho trường THPT (GDPT 2018, học 2 buổi). Chạy hoàn toàn trên trình duyệt, dữ liệu lưu tại máy người dùng.

**Dùng ngay:** https://hongbupcva.github.io/ndgroup-xep-tkb-thpt/

## 5 bước
1. Khai báo trường, số ngày/tiết, môn học (tối đa tiết/ngày, phòng/sân dùng chung, tiết cấm, tiết cố định).
2. Giáo viên (tổ, tối đa tiết/ngày, số ngày dạy, lịch bận) và lớp (khối, buổi chính, GVCN, lịch nghỉ).
3. Phân công Lớp × Môn (GV, số tiết, tiết đôi, buổi chính/phụ) — có dán từ Excel.
4. Xếp tự động, chỉnh tay có gợi ý (xanh/cam/mờ), khoá tiết, tối ưu tiếp, lưu phương án.
5. Xuất Excel (toàn trường, từng lớp, từng GV, theo tổ, phân công), in/lưu PDF, sao lưu .json.

Bấm **Nạp dữ liệu mẫu** để thử với trường mẫu 18 lớp.
